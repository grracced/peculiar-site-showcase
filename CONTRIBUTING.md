# Contributing to VerifAI

Thank you for investing your time in contributing to our project!

## Development Workflow
1. Fork the repo and create your branch from `develop`.
2. Ensure you have read `docs/Developer_Handbook.md`.
3. If you've added code that should be tested, add tests.
4. Ensure the test suite passes (`pnpm run test`).
5. Ensure your code passes linting (`pnpm run lint`).
6. Format your code (`pnpm run format`).
7. Issue that pull request!

## Commit Messages
We follow Conventional Commits (e.g., `feat(ui): add dashboard button`).
